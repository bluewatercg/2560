# 2560 缩量回踩当前规则

> 文档属性：当前口径说明
>
> 用途：面向阅读和讨论的简化规则说明，帮助快速理解系统当前常用筛选口径。
>
> 这不是 canonical 目标规则文档，也不是完整实现说明。若涉及工程落地或 v1.2.2 目标规则，请以 `docs/2560短线结构算法统一改造方案_v1.2.2_FinalFreeze.md` 为准。

## 一、核心筛选条件

先找满足以下条件的股票：

| 条件 | 含义 |
|---|---|
| 25日线向上 | 中期趋势不能走弱 |
| 5日均量线 > 60日均量线 | 近期资金活跃度高于长期均量 |
| 收盘价 >= 25日线 | 股价已经站上25日线，不能跌破 |
| 25日线位置% <= 3% | 股价在25日线附近，属于有效回踩区 |
| 缩量 / 小K线 / 小阴小阳 | 当前不是放量追高，而是回踩整理 |

输出为：

```text
缩量回踩25日线候选池
```

## 二、25日线位置%的解释

`25日线位置%` 不是“还差多少到25日线”，而是：

```text
(收盘价 - 25日线) / 25日线 * 100%
```

| 数值 | 意思 |
|---|---|
| 0% | 刚好在25日线 |
| +1% | 收盘价高于25日线1% |
| +3% | 高于25日线3%，仍在有效回踩区上沿 |
| 负数 | 收盘价低于25日线，代表跌破 |

当前候选池优先看：

```text
0% 到 3%
```

也就是“已经站上25日线，但离25日线不远”。

## 三、近3日涨幅%

这个不是单日涨幅，而是最近 3 个交易日累计涨幅：

```text
(报告日收盘价 - 3个交易日前收盘价) / 3个交易日前收盘价 * 100%
```

| 近3日涨幅% | 判断 |
|---|---|
| <=5% | 正常 |
| 5%-8% | 偏热，观察 |
| 8%-20% | 高位，谨慎 |
| >20% | 过滤 |

核心规则：

```text
近3日涨幅超过20%就不看了
```

原因是即使技术形态满足，短线已经涨太多，买入意义不大，容易追高。

## 四、热点主线规则

热点主线不是硬性买入条件，而是排序和方向参考。

| 状态 | 处理 |
|---|---|
| 技术满足 + 行业热点方向强匹配 | 优先看 |
| 技术满足 + 行业热点方向弱匹配 | 保留 |
| 技术满足 + 无热点匹配 | 不淘汰，但优先级降低 |
| 技术不满足 + 热点很强 | 不放行，仍淘汰 |

一句话：

```text
2560 技术条件决定能不能进池，行业热点方向决定优先看谁。
```

## 五、公告风险规则

公告风险是风控项，优先级高于热点。

| 公告情况 | 处理 |
|---|---|
| 减持、立案、问询函、监管函、处罚等 | 高风险提示 |
| 解禁、亏损、诉讼、质押等 | 中风险提示 |
| 无命中 | 无公告风险命中 |
| cninfo 联网失败 | 显示“公告联网受限，暂未验证” |

有重大减持、立案类风险时，即使技术形态好，也要降权或暂缓。

## 六、最终一句话规则

```text
25日线向上
+ 5日均量线 > 60日均量线
+ 收盘价站上25日线
+ 25日线位置% <= 3%
+ 小K线/小阴小阳/缩量
+ 近3日涨幅 <= 20%
+ 公告无重大风险
+ 优先选择行业热点方向匹配的标的
```

最终输出字段建议保持：

```text
代码、名称、收盘价、25日线位置%、近3日涨幅%、短线过热状态、压量形态、量比、买点类型、行业热点方向、公告风险
```
