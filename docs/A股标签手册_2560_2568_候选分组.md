# A股标签手册：2560 技术标签、2568 标注标签与候选分组

> 文档用途：给懂 A 股、但不看程序的人解释这套标签体系的设计思路。
>
> 阅读目标：看懂系统如何把一只股票从“技术结构”一路推导到“最终候选结论”。
>
> 文档口径：以当前系统实际业务口径为准，强调规则表达，不讨论程序实现细节。

## 1. 这套系统到底在做什么

这套体系不是在回答“这只股票能不能涨”，而是在回答三个更具体的问题：

1. 这只股票当前有没有进入短线观察范围的技术结构。
2. 这只股票除了技术结构之外，还有没有亮点、风险和人工复核价值。
3. 在盘后复盘场景里，这只股票最终应该被放进 `focus`、`watch` 还是 `reject`。

可以把它理解成三层：

| 层级 | 作用 | 输出结果 |
|---|---|---|
| `2560 技术标签层` | 判断量价趋势结构是否成立 | `#结构完整`、`#缺量`、`#未突破` 等 |
| `2568 标注层` | 用更接近交易员语言的方式总结亮点与风险 | `强势票｜重点关注`、`风险较多｜建议移出` 等 |
| `最终候选分组层` | 把技术、题材、环境、位置等综合起来，形成盘后候选结论 | `focus / watch / reject` |

一句话概括：

`2560` 决定“技术结构像不像样”，`2568` 决定“这只票值不值得人工盯”，最终分组决定“明天该把它放到哪个候选框里”。

---

## 2. 三层之间的关系

很多人第一次看这套体系，最容易混淆三件事：

| 容易混淆的概念 | 实际含义 |
|---|---|
| `2560 命中` = 一定能做 | 不是。2560 只是技术结构层的基础筛选。 |
| `2568 强势票` = 一定进 `focus` | 不是。2568 是标注语言，不直接替代最终候选结论。 |
| `focus / watch / reject` 只是技术排序 | 不是。最终分组还受题材强度、题材地位、短期过热、环境等约束。 |

正确的理解顺序应该是：

1. 先看 `2560` 技术结构有没有站住。
2. 再看 `2568` 是在强调亮点，还是在暴露风险。
3. 最后才看这只票是否进入 `focus / watch / reject`。

所以，这不是一套“单一打分系统”，而是一套“逐层过滤 + 逐层解释”的规则体系。

## 3. 2560 技术标签手册

### 3.1 2560 的核心任务

`2560` 的核心任务，是从全市场里先找出“具有短线观察价值的技术结构”。

当前最核心的技术口径可以概括为：

- 25 日线不能走坏
- 股价不能有效跌破 25 日线
- 近期量能不能明显衰竭
- 不能已经冲到明显高位或过热段
- 最好处在“回踩后待确认”而不是“放量追高”

换句话说，`2560` 不是追求最强势，而是先找“结构还在、位置还行、可以继续观察”的票。

### 3.2 2560 标签总表

| 标签 | 一句话定义 | 对候选结论的大方向影响 |
|---|---|---|
| `#结构完整` | 关键负面条件都没有出现 | 明显偏正面 |
| `#缺量` | 量能结构不达标 | 偏负面 |
| `#高位` | 已接近压力区或位置偏高 | 偏负面 |
| `#震荡` | 波动率不足，结构不够活跃 | 偏负面 |
| `#未突破` | 还没形成有效突破 | 中偏负面 |
| `#逆势` | 价格处在核心趋势线下方 | 偏负面 |
| `#趋势走弱` | 趋势斜率走弱 | 偏负面 |
| `#未确认` | 回踩确认或右侧确认不充分 | 中偏负面 |
| `#偏离MA25` | 离 25 日线太远，不像有效回踩 | 偏负面 |
| `#MA25走弱` | 25 日线本身已经开始转弱 | 偏负面 |
| `#数据不足` | 数据无法支持稳定判断 | 直接降级 |

### 3.3 `#结构完整`

**一句话定义**
当一只股票没有被打上核心负面标签时，系统会给它 `#结构完整`。

**市场含义**
说明这只票至少在当前口径下，趋势、位置、量能、确认关系没有明显破坏。

**常见出现背景**

- 价格贴近 25 日线
- 25 日线仍在向上
- 量能结构没有失真
- 没有明显跌破趋势线
- 没有明显数据缺失

**对最终分组的影响**
这是偏正面的基础标签，但它本身不保证一定进 `focus`。如果题材不够、位置不够、过热或环境不佳，仍然可能只是 `watch`。

**容易误解的地方**
`#结构完整` 不是“明天一定可做”，只是说明技术底子没有明显坏掉。

### 3.4 `#缺量`

**一句话定义**
量能没有达到系统要求，近期成交活跃度不足。

**市场含义**
短线结构里，价和量必须配合。没有量，结构的可信度就会下降。

**常见出现背景**

- 5 日均量没有站上 60 日均量
- 或者量比达不到最基本要求

**对最终分组的影响**
这是很典型的拖后腿标签。即使其他结构还可以，也容易把候选从 `focus` 拉低到 `watch`，严重时直接 `reject`。

**容易误解的地方**
不是说“今天缩量就一定不好”。这里的重点不是单日缩量，而是“整体量能结构没有跟上”。

### 3.5 `#高位`

**一句话定义**
价格已经逼近阶段压力区，继续上冲的风险变大。

**市场含义**
短线看的是风险收益比。位置太高，即使技术还好，也容易进入不划算的追高区。

**常见出现背景**

- 股价已经接近前高、箱体上沿或阶段压力

**对最终分组的影响**
对 `focus` 很不友好，常常会把“原本技术上还能看”的票打回观察或淘汰。

**容易误解的地方**
`#高位` 不是说股票一定见顶，而是说“从短线观察视角看，位置不再舒服”。

### 3.6 `#震荡`

**一句话定义**
波动率不够，结构缺乏主动性。

**市场含义**
有些票趋势没坏，但也没有短线出手价值，因为它不动，或者动得没有效率。

**常见出现背景**

- 波动幅度不足
- 结构太平，像在无效横盘

**对最终分组的影响**
通常降低优先级，更容易留在 `watch`，很难进入高优先级候选。

### 3.7 `#未突破`

**一句话定义**
股票还没穿过系统定义的关键压力或突破位。

**市场含义**
说明结构还在酝酿，没有进入更明确的右侧阶段。

**常见出现背景**

- 价格没有有效越过近 20 个周期的重要高点

**对最终分组的影响**
更偏向“可观察、待确认”，而不是“已经具备明确推进条件”。

### 3.8 `#逆势`

**一句话定义**
价格处在核心趋势线下方。

**市场含义**
这说明票的技术位置不在安全侧，做短线时胜率和容错都会变差。

**常见出现背景**

- 收盘价跌回主要趋势线下方

**对最终分组的影响**
属于强负面项，经常直接推向 `reject`。

### 3.9 `#趋势走弱`

**一句话定义**
趋势线本身的斜率不再健康。

**市场含义**
不是只看站不站上均线，还要看均线自己是在往上还是在转弱。

**常见出现背景**

- MA 斜率趋平
- MA 斜率转负

**对最终分组的影响**
对短线候选伤害较大，因为这意味着结构的“动能方向”开始变差。

### 3.10 `#未确认`

**一句话定义**
系统认为回踩后的右侧确认还不够。

**市场含义**
这类票不是不能看，而是还没完成“值得提高优先级”的确认动作。

**常见出现背景**

- 回踩后没站稳
- 缺少右侧阳线确认

**对最终分组的影响**
更容易进入 `watch`，不容易直接给高优先级。

### 3.11 `#偏离MA25`

**一句话定义**
价格离 25 日线太远，不再像标准回踩结构。

**市场含义**
系统偏好的是“围绕 25 日线的有效整理”，而不是离线过远之后再硬解释成回踩。

**对最终分组的影响**
会削弱“缩量回踩”这类结构成立的基础。

### 3.12 `#MA25走弱`

**一句话定义**
25 日线本身已经开始转弱。

**市场含义**
这通常代表中短期节奏不再健康，即使股价当日看着还行，结构底层已经没那么漂亮。

**对最终分组的影响**
这是典型的基础门槛风险，容易触发淘汰。

### 3.13 `#数据不足`

**一句话定义**
关键数据缺失或质量不足，无法做稳定判断。

**市场含义**
不是看坏，而是“不敢下结论”。

**对最终分组的影响**
会直接让结构状态降到“数据不足”，属于强制降级。

### 3.14 2560 的结构状态

系统不会只给单个标签，还会给一个总的结构状态：

| 结构状态 | 含义 |
|---|---|
| `结构完整` | 基本没有负面技术标签 |
| `部分满足` | 有少量问题，但结构还没有完全坏 |
| `明显缺失` | 负面条件较多，短线结构不够成立 |
| `数据不足` | 无法稳定判断 |

这四个状态更像“结构健康度总览”，便于快速复盘。

## 4. 2568 标注标签手册

### 4.1 2568 的任务是什么

如果说 `2560` 是“技术筛子”，那么 `2568` 更像“交易员语言翻译器”。

它不直接做最终分组，而是把一只票的亮点、风险和人工关注价值表达得更直观。核心原则是：

- 不靠总分说话
- 不替代最终候选分组
- 重点输出“哪里强、哪里弱、值不值得人工复核”

### 4.2 2568 的三类输出

| 输出层 | 作用 |
|---|---|
| `硬性状态` | 用“站上 MA25、均量放量、趋势结构健康”等判断基础体质 |
| `亮点标签` | 把趋势、量能、结构、安全边界翻译成更直观的短语 |
| `人工建议` | 用 `强势票｜重点关注` 等结论给人工复核者一个处理建议 |

### 4.3 2568 的硬性状态

当前系统重点看 5 个硬性状态：

| 状态项 | 偏正面表达 | 偏负面表达 | 市场含义 |
|---|---|---|---|
| MA25 方向 | `✔ MA25 上行` | `✘ MA25 下弯` | 短中期节奏有没有坏 |
| MA60 方向 | `✔ MA60 上行/走平` | `✘ MA60 下行` | 中期背景是否稳定 |
| 价格位置 | `✔ 站上 MA25` | `✘ 跌破 MA25` | 价格是否站在核心线上方 |
| 均量关系 | `✔ 均量放量` | `✘ 均量不足` | 量能是否支持结构 |
| 趋势结构 | `✔ 趋势结构健康` | `✘ 趋势结构弱` | MA25 是否在 MA60 上方 |

### 4.4 A / B / C / D 亮点体系

`2568` 的亮点体系不是在算收益，而是在把一只票拆成“亮点”和“风险”。

可以把它简单理解成：

| 级别 | 含义 |
|---|---|
| `A` | 强亮点，属于核心优点 |
| `B` | 正常亮点，说明结构较健康 |
| `C` | 中性描述，不算强，也不算坏 |
| `D` | 风险项，提示结构或位置上的问题 |

### 4.5 常见 A 类亮点

| 标签 | 一句话定义 | 市场含义 |
|---|---|---|
| `⭐ 趋势双线共振` | MA25、MA60 同步向上 | 趋势背景较强 |
| `🔥 强放量` | 量能明显强化 | 资金参与度高 |
| `🟩 结构强` | 结构位置、节奏较优 | 技术形态更完整 |
| `🟩 回踩确认` | 回踩后确认较充分 | 更接近可跟踪的右侧形态 |

### 4.6 常见 B 类亮点

| 标签 | 一句话定义 | 市场含义 |
|---|---|---|
| `🟦 趋势主升段` | 结构处于偏强运行阶段 | 有延续性预期 |
| `⭐ 放量良好` | 量能比较配合 | 不是最强，但够用 |
| `🟦 结构一般` | 结构尚可，但不是顶级形态 | 可继续观察 |
| `🟦 趋势健康` | 趋势总体没坏 | 有基础，但不一定出彩 |

### 4.7 常见 C 类标签

| 标签特征 | 含义 |
|---|---|
| 以 `~` 开头的描述 | 代表中性状态，既不明显加分，也不明显减分 |

这类标签的作用主要是“补充描述”，而不是直接推动最终分组。

### 4.8 常见 D 类风险

| 标签类型 | 市场含义 |
|---|---|
| `⚠` 开头 | 风险提示，但不一定彻底否定 |
| `❌` 开头 | 结构明显偏弱 |
| `✘` 开头 | 硬性状态不满足 |

此外，以下内容也会并入 D 类风险：

- 风险标签本身，如连续缩量、跌破 MA25、大阴破位、加速段等
- `MA25 下弯`
- `MA60 下行`

### 4.9 2568 的人工建议标签

这是最适合给懂股票的人看的一组标签，因为它已经很接近人工复盘语言。

| 人工建议标签 | 含义 | 常见对应场景 |
|---|---|---|
| `强势票｜重点关注` | 核心亮点较多，人工应优先看 | A 类亮点明显 |
| `有核心亮点｜可关注` | 有值得看的点，但还没到最强 | 至少有重要亮点 |
| `中强票｜观察池` | 结构不差，但更适合观察 | B 类亮点较多 |
| `健康趋势｜可观察` | 趋势健康，但爆发力一般 | 基础不错，缺强刺激 |
| `风险较多｜建议移出` | 风险项过多，不建议继续重点跟踪 | D 类风险明显堆积 |
| `风险偏多｜谨慎观察` | 还能看，但需要收缩预期 | 风险多于亮点 |
| `有风险｜人工确认` | 不宜直接给乐观结论 | 有明显单项风险 |
| `普通结构｜低优先级` | 没有特别亮点，也没有形成高价值观察点 | 平庸结构 |

### 4.10 `summary_label` 的三档口径

系统还会给出一个更粗的结构标签：

| 标签 | 含义 |
|---|---|
| `强满足` | 基础状态较强，且没有明显风险拖累 |
| `临界` | 有一定亮点，但还没到明确强结构 |
| `弱满足` | 结构偏弱，更多是排查对象 |

这三个词适合做总览，不适合单独替代最终交易结论。

## 5. 最终候选分组手册：focus / watch / reject

### 5.1 这一层为什么存在

前两层解决的是“结构”和“描述”，第三层解决的是“盘后结论”。

最终分组要回答的是：

- 明天最值得优先跟踪的是谁
- 哪些票可以留在观察池
- 哪些票当前不该进入候选名单

### 5.2 最终分组不是只看技术

最终分组综合考虑的维度包括：

| 维度 | 作用 |
|---|---|
| 技术结构 | 决定票有没有基本资格 |
| 量能结构 | 决定结构是否有资金配合 |
| 短期过热状态 | 决定是不是已经涨过头 |
| 热点主线强度 | 决定是否站在主流方向上 |
| 题材地位 | 决定它是龙头、强跟随，还是边缘票 |
| 盘中确认 | 决定右侧动作是否成立 |
| 压力位关系 | 决定向上空间是否受压 |
| 市场环境 | 决定大背景对成功率是否友好 |

### 5.3 `focus`

**一句话定义**
综合条件通过后，优先级最高的候选组。

**市场含义**
它不是“必买组”，而是“盘后复盘里最值得优先跟踪的一组”。

**通常需要具备的特征**

- 技术硬条件没有明显破坏
- 总体评分达到高标准
- 题材方向不能太弱
- 个股在题材里不能过于边缘

**适合怎么理解**

`focus` = 候选名单里的核心席位。

### 5.4 `watch`

**一句话定义**
有一定观察价值，但暂时不够资格进入最高优先级。

**市场含义**
常见于“技术还行，但少一个关键确认”或“结构可以，但题材地位不够强”的股票。

**常见出现背景**

- 技术过关，但总分没到 `focus`
- 技术过关，但题材地位只够跟随，不够核心
- 结构还可，但更像等待下一步确认

**适合怎么理解**

`watch` = 可以继续放在雷达里，但不应和核心候选混为一谈。

### 5.5 `reject`

**一句话定义**
当前口径下不应进入候选池。

**市场含义**
不是说股票没有任何投资价值，而是说“按这套短线规则，现在不该把它列入有效候选”。

**常见触发原因**

- 距离核心均线太远
- 25 日线方向转弱
- 量能结构不成立
- 股价跌回核心线下方
- 短期已进入过热段
- 热点强度不足
- 最终综合评分过低

### 5.6 一个很重要的设计原则

这套系统里，`reject` 不等于“垃圾票”，而是“不符合当前这套短线候选口径”。

这点非常重要，因为很多懂股票的人会本能地把 `reject` 理解成否定个股质量。
实际上这里否定的是“当前这一天、当前这套短线规则下的候选资格”。

---

## 6. 规则串联：一只票是怎么被层层判断的

### 案例一：技术好，最终进入 `focus`

典型路径：

1. `2560` 层面没有明显负面标签，或基本接近 `#结构完整`
2. `2568` 给出 `强势票｜重点关注` 或者至少有明显 A 类亮点
3. 热点主线匹配度较高
4. 个股在题材中不是边缘角色
5. 短期涨幅没有进入过热过滤区
6. 最终进入 `focus`

这种票代表的是：技术结构、方向、位置和优先级都比较统一。

### 案例二：技术上不差，但最终只进 `watch`

典型路径：

1. `2560` 基本成立，没有被硬性淘汰
2. `2568` 可能给出“有核心亮点｜可关注”或“健康趋势｜可观察”
3. 但题材地位一般、右侧确认不足、或最终综合强度不够
4. 最终进入 `watch`

这种票代表的是：有看点，但还不到核心候选级别。

### 案例三：表面强势，最终仍然 `reject`

典型路径：

1. 看起来很活跃，甚至单日很强
2. 但离 25 日线过远、位置过高、短期涨幅过热，或者已经跌回核心线下
3. `2568` 里风险项堆积
4. 最终被归入 `reject`

这种票体现的是系统的一个核心设计原则：

`短线强，不等于短线可跟。`

---

## 7. 这套设计背后的核心思想

如果要用几句话把这套标签体系的设计思路讲给懂股票的人听，我建议这样概括：

### 7.1 先看结构，再看故事

热点、题材、公告都重要，但第一步先看技术结构有没有站住。
没有结构，故事再好也只能降级处理。

### 7.2 不把“强势”直接等同于“可做”

很多短线票最容易出问题的地方，不是它不强，而是它已经太强、太远、太热。
所以系统会特别关注：

- 是否远离 25 日线
- 是否接近压力位
- 是否进入加速过热段

### 7.3 让标签承担“解释责任”

这套系统不是只吐一个结果，而是要求每个结果都能被解释：

- 为什么结构不完整
- 为什么是重点关注
- 为什么只是观察
- 为什么被淘汰

这也是为什么要同时保留 `2560`、`2568` 和最终分组三层表达。

### 7.4 最终结论必须是“候选语言”，不是“预测语言”

这套系统的输出不是“明天必涨”，而是：

- 明天谁值得优先盯
- 谁可以继续跟
- 谁现在不应纳入候选

它服务的是盘后复盘和次日观察，不是神谕式预测。

## 8. 容易混淆的概念对照表

| 概念 A | 概念 B | 正确理解 |
|---|---|---|
| `2560 命中` | `focus` | `2560` 是技术入围，不等于最终核心候选 |
| `2568 强势票` | `focus` | `2568` 是人工标注语言，不直接替代最终分组 |
| `结构完整` | `一定可做` | 结构完整只说明技术底子没明显坏 |
| `watch` | `看空` | `watch` 不是看空，而是“保留观察，但不升到最高优先级” |
| `reject` | `股票不行` | `reject` 是否定当前短线候选资格，不是永久否定个股 |
| `放量` | `一定加分` | 放量也要看位置和结构，不能脱离背景单独解读 |
| `热点强` | `一定放行` | 热点只能提高优先级，不能替代技术硬条件 |

## 9. 一页话术版总结

如果只用一段话把整套设计思路讲给懂股票的人看，可以这样说：

> 这套体系把短线候选分成三层。第一层 `2560` 只管技术结构，重点看 25 日线、量能结构、回踩确认、压力位置和短期过热，解决“这只票有没有进入观察范围的技术资格”。第二层 `2568` 用更接近交易员语言的方式，把亮点、风险和人工关注价值表达出来，解决“这只票到底强在哪、弱在哪、值不值得继续盯”。第三层再把技术、题材、位置、环境综合成 `focus / watch / reject`，解决“盘后复盘里，这只票该放进哪个候选框”。因此，这不是单纯打分系统，而是一套逐层过滤、逐层解释的候选管理规则。

## 10. 建议的使用方式

如果这份手册是拿给懂股票的人审你的设计，我建议按这个顺序讨论：

1. 先让他认同“三层结构”是不是合理。
2. 再逐条看 `2560` 的负面标签是否符合短线常识。
3. 再看 `2568` 的人工语言是否贴近实盘复盘。
4. 最后讨论 `focus / watch / reject` 的边界是否清晰。

这样最容易把讨论集中在“口径对不对”，而不是陷进实现细节。
