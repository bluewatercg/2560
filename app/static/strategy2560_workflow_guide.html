2560结构分析系统工作流指导

用于说明每天应该点什么、什么时候用手动计算、什么时候用任务队列、怎么看结果。
① 数据准备
下载中金数据先在客户端完成日线和5分钟数据更新。
→
导入 daily / lc5通过数据导入页面入队，后台 worker 执行。
→
聚合 30m通过 30m 构建入口入队，按 job 进度刷新。
② 指标计算
重算 technical_indicator脚本：rebuild_technical_indicator.py
负责 MA / ATR / VOL / 偏离度。
→
指标缓存完成2560扫描只读指标，不再重复计算。
③ 任务执行
手动计算少量股票测试；不要用于全市场正式任务。
任务队列正式入口：all/sh/sz + shards + priority。支持入队和立即执行。
→
run_2560_analysis扫描信号，写 structure_2560_analysis。
④ 结果查看
最新分析结果每只股票一行，看最近一次分析状态。
信号列表历史事件视图，看发生过的2560信号。
任务队列看 job_queue / job_execution / job_task_item。
批次管理看每次 run 的 batch。

日常收盘后怎么用

  • 先下载中金数据。
  • 执行增量更新脚本或在任务队列中入队全市场任务。
  • 完成后看「最新分析结果」和「信号列表」。

什么时候用哪个页面

  • 手动计算：单只/少量股票调试。
  • 任务队列：正式全市场、并行、定时任务。
  • 最新分析结果：每股票最近状态。
  • 信号列表：历史信号事件。
