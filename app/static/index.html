2560 WORKFLOW

每天应该怎么用这套系统？

这页只做一件事：告诉你什么时候更新数据、什么时候算指标、什么时候用任务队列、 结果应该看哪个页面。

推荐入口 正式全市场任务 → 任务队列
1 数据准备 下载 / 导入 / 聚合
→
2 指标计算 technical_indicator
→
3 任务执行 手动 / 队列
→
4 结果查看 最新状态 / 信号
①

数据准备

先保证行情数据是新的，然后再做后续计算。

  • 先做：中金客户端完成日线和 5 分钟数据下载。
  • 导入：数据导入页面入队，后台 worker 执行。
  • 聚合：30m 构建入队，按 job 进度刷新。
Job Queue / 盘后数据更新
②

指标计算

统一生成 MA、ATR、VOL、偏离度等技术指标。

  • 脚本：rebuild_technical_indicator.py
  • 2560 扫描阶段只读取指标，不重复计算。
  • 这是后续信号质量的基础。
technical_indicator
③

任务执行

这里最容易混淆，记住一句话：小任务用手动，大任务用队列。

  • 手动计算：只用于单只或少量股票测试。
  • 任务队列：用于 all / sh / sz 正式批量任务。
  • shards：并行分片数，例如 4 表示拆成 4 份。
  • priority：任务优先级，数字越小越优先。
正式任务入口：任务队列
④

结果查看

不同页面看不同结果，不要把“信号列表”和“最新状态”混在一起。

  • 最新分析结果：每只股票一行，看最近一次状态。
  • 信号列表：历史信号事件。
  • 任务队列：看执行进度、队列、分片明细。
  • 批次管理：看每次 run 的 batch。
